Setup Instructions

To share this with your league:

Option 1 - GitHub Pages (Recommended):
1. Create a free GitHub account at github.com
2. Create a new repository (e.g., "golf-league")
3. Upload this HTML file
4. Go to Settings → Pages → Enable GitHub Pages
5. Share the URL with your league (e.g., username.github.io/golf-league)

Option 2 - Netlify Drop:
1. Go to app.netlify.com/drop
2. Drag and drop this HTML file
3. Get your shareable link instantly

To update scores for everyone:
1. Enter tournament data on YOUR device
2. Click "Export Data" and download the JSON file
3. Upload the updated HTML file + JSON to your hosting
4. Friends refresh the page to see updates
