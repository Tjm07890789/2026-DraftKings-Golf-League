Data Management

Export your data after entering scores each week. Share the exported file so others can import and view results on their own device.

Updating Scores for Your League

Each week after entering scores:
1. Click Export Data — this downloads a small JSON file.
2. Go to your GitHub repository and click the existing index.html file.
3. Click the pencil (edit) icon → then go back to the repo root.
4. Drag and drop the exported .json file — but actually the easiest path is:
   • On your Mac, open index.html in a text editor
   • Replace the contents with this updated file
   • Upload to GitHub (drag & drop into the repo)
5. Friends refresh the page — done!

Tip: The easiest weekly workflow is to always use the same device for score entry, export data, then share the JSON file directly with your league via text/email so they can import it themselves.
